\noindent\textbf{Call accounting.} One \emph{call} is one request to a generation API,
whatever its length. It can go to the model under test, the paraphrase generator, or the judge.
Calls are counted per case at evaluation time; the budget $k$ is the batch mean.
Everything replayed from the cache is free.
